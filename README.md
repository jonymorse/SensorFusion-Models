# ForgeCAD box

This folder contains a minimal ForgeCAD setup with one parametric box model.

## Commands

```powershell
npm.cmd run check
npm.cmd run preview
npm.cmd run export:step
npm.cmd run studio
```

PowerShell script execution is disabled on this machine, so use `npm.cmd` and
`forgecad.cmd` rather than the `.ps1` shims.
